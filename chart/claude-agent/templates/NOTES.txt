1. Add this once to ~/.ssh/config. The Gateway passes TLS through; the pod's
   tls sidecar terminates it with certificate {{ include "claude-agent.fullname" . }}-tls.

   Host *.{{ .Values.ssh.domain }}
     User agent
     ProxyCommand openssl s_client -quiet -verify_return_error -servername %h -connect %h:443

   ssh {{ $host }}

   shell), then /config -> "Enable Remote Control for all sessions".
